# Library-HM

一款适配鸿蒙系统的阅读器，优先面向平板设备，提供简洁、舒适的本地阅读体验。

## 页面结构

- **首页**：居中搜索框，未登录展示热门图书，登录后展示个性化推荐；右上角账号入口使用居中登录弹窗。
- **书籍详情**：点击首页书籍封面或书名打开，展示完整简介和上游提供的出版、文件信息；可以收藏或前往书架，返回继续浏览原列表。
- **书架**：独立于账号的本地书架，展示收藏、文件导入、下载状态和阅读历史，支持搜索、筛选和排序；右上角不显示账号信息。
- **阅读器**：从书架打开的独立页面，不占用底部导航；远程书籍必须先下载，本地导入的文件无需重复下载。

底部“首页”和“书架”收拢为居中悬浮胶囊，选中项使用蓝色图标与文字；列表末尾预留滚动空间。

搜索结果与热门/推荐保留独立滚动状态，每次新搜索从顶部显示，返回发现列表保留原位置。首页登录、退出和收藏成功提示，以及详情页收藏成功提示，约 3 秒后自动消失；收藏状态保留。

界面通过亮色与深色资源跟随鸿蒙系统配色，覆盖页面、弹窗、导航、图标与书架层板；书籍封面保留原图。

## 开发环境

- ArkTS + ArkUI，Stage 模型，单 `entry` 模块。
- 兼容及目标版本：HarmonyOS 5.0.0（API 12），设备类型为平板。
- 使用 DevEco Studio 打开仓库根目录，同步工程后构建 `entry` 模块。
- 真机运行前，在 DevEco Studio 中配置本地签名。签名密钥不纳入仓库。

构建工具由 DevEco Studio 提供，工程未附带旧版 Hvigor wrapper，也没有额外的第三方业务依赖。

## 项目状态

已建立原生应用工程与两个底部入口，登录、搜索、推荐和账户信息采用真实网络仓库，业务请求统一经过客户端封装：

- 请求层提供 HTTPS、查询参数、JSON/表单、超时、取消与错误分类，不自动重试、不记录凭证或请求体。
- 会话通过鸿蒙 ASSET 安全存储保持登录；密码不保存，启动后向书源验证，确认失效或退出登录时删除本地密钥。
- 热门与个性化推荐分别请求各自接口，切换账户后替换列表；生产装配不填充示例书目。
- 书籍详情复用统一 HTTP：无会话时匿名请求，有会话时携带鉴权；在原列表显示普通 loading，详情加载完成后淡入页面，失败时可重试或取消。详情连接超时 30 秒、读取超时 60 秒；缺失字段隐藏，不提供下载或直接阅读入口。
- 远程封面通过无鉴权 HTTP 客户端加载，提供有界内存缓存和失败占位；长书名与作者名限制显示行数。
- 书架收藏与阅读记录仍保存在内存，退出账户不会清空书架。
- PDF、EPUB 文件选择、下载、解析、渲染和持久化尚未实现。
- 书架已建立未下载、下载中、失败重试和本地文件就绪的状态流转；当前下载适配器明确提示未接入，不制造成功结果。
- 远程书籍只保存元数据与接口标识；文件就绪前不能进入阅读器或新增进度。

2026-11-27，书籍详情与首页联调及评审修复通过 `npm run ci` 的 110 项测试、官方 Lint（0 错误、4 条警告）、原生编译与调试签名打包。回归包含详情、封面、缓存、真实错误判断、列表版本隔离，以及提示到期、关闭与切换书籍后旧计时失效。

此前平板横屏已验证 loading 至完整详情的显示顺序、系统返回，以及推荐滚动后搜索回顶、再次搜索回顶、返回推荐保留位置、首页收藏提示自动消失；也已验证真实封面和 20 条搜索结果。本轮详情页提示修复时未连接设备，尚未安装复验。竖屏、完整亮暗切换、取消与网络故障交互、详情返回的精确滚动位置仍待真机验收；会话长期恢复、文件下载落盘与文档渲染尚未完成验收。

本地架构说明与后续替换位置见 `docs/architecture.md`，协作规则见 [AGENTS.md](AGENTS.md)。

## CI/CD

使用 Node.js 24–26 执行开发检查：

```text
npm ci --ignore-scripts --no-audit --no-fund
npm run ci
```

推送分支和创建 PR 后，GitHub Actions 自动执行工程与资源检查、分层依赖检查、基础格式与凭证扫描、纯逻辑类型检查和回归测试。PR 还检查标题格式与关联 issue。

独立的 `HarmonyOS Gate` 在 GitHub 托管的 Ubuntu runner 上安装并校验固定版本的华为命令行工具，自动执行官方 Code Linter 和 Hvigor 原生编译，保存检查报告与未签名 HAP。合并规则要求基础检查和原生检查均通过；本地 `npm run ci` 只执行辅助检查。工具版本、验证边界与规则设置见 [CI/CD 说明](docs/ci.md)。
